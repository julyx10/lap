# Release Notes - Lap v0.4.1

v0.4.1 is a hotfix for a crash on macOS: opening or switching videos in Preview could close the app unexpectedly, especially in folders that mix photos and videos. The crash is fixed in this release. It also adds customizable status bar fields and fixes a Linux window issue.

## Highlights

- **macOS video crash fixed** — Lap no longer quits while you open a video in Preview or move between clips with the arrow keys. Photo-only folders were never affected. (#558)
- **Customizable status bar** — Choose which fields the status bar shows, including name and size, dimensions, folder, album, color information, capture date, camera, lens, exposure, and location. (#460)

## New Features and Improvements

- Status bar fields can be shown, hidden, and reordered from a dialog that also opens by right-clicking the status bar; Settings has an entry point for the same dialog. (#460)
- Reordering smart albums and collections moved into each panel's menu, keeping the rows themselves uncluttered.
- Cleaning unused thumbnail cache moved from the library manager to **Settings → Storage**, where it can clean all listed libraries in one pass.

## Bug Fixes

- The main window is opaque again on Linux, where it could become see-through, and the default window size now matches the other platforms. (#554)
- Cropping and editing no longer fail on images whose content does not match their extension, such as a PNG saved as `.jpg`. (#563)
- The grid no longer flashes a grey background when switching views.
- Similar image counts are only requested when the duplicate panel asks for an analysis.

## Downloads and Updates

Download the matching macOS, Windows, Linux DEB, or AppImage package from the [v0.4.1 release](https://github.com/julyx10/lap/releases/tag/v0.4.1). See [Getting Started](/guide/getting-started) for installation and update guidance.

For AppImage installations, download the new AppImage instead of using the built-in updater. The embedded update information and `.zsync` files support delta updates through compatible external tools such as AppImageUpdate and AppImageLauncher.
