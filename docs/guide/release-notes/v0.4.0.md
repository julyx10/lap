# Release Notes - Lap v0.4.0

v0.4.0 is about metadata and organization: EXIF / IPTC / XMP import and XMP writeback, a tag tree, RAW pairs handled as single items, keep rules for the duplicate finder, batch rename, and a new File Info panel. Large libraries browse faster, cloud-only files work without downloading, and there are two new languages (17 total).

## Highlights

- **Metadata (EXIF / IPTC / XMP)** — Lap reads embedded metadata via exiftool-rs and imports XMP sidecars: ratings, favorites, tags, culling flags, GPS, capture dates, and text fields (title, headline, description, creator, copyright). Sidecar values take precedence over embedded ones, and local edits are preserved. The text fields are editable in Lap, and "Save Metadata to XMP" writes them along with tags, ratings, favorites, and culling states back to sidecars without touching unrelated properties. Sidecars follow files through rename, move, copy, delete, and import. (#7, #40, #244, #282, #341, #379, #402, #439)
- **Hierarchical tags** — Tags moved from groups into a tree. Drag to reorder or reparent subtrees, search and count including descendants, edit inline. The list is virtualized and has a selected-only filter. Deleted tags stay deleted after reimport, and digiKam hierarchical keywords no longer create duplicates. (#422, #480, #524, #541, #542)
- **RAW pairs as single items** — RAW+JPEG/HEIC pairs and Live Photos act as one item in browsing, selection, import, drag-and-drop, clipboard, and dedup. Deleting a pair lets you choose both sides or just one, and a clipboard setting controls whether copies include both files, only the RAW, or only the JPEG. (#469, #520, #555)
- **Duplicate keep rules** — Set an ordered list of preferred folders plus format, size, and date rules, and Lap marks the KEEP side automatically in duplicate and similar scans. RAW/JPEG pairs are protected, and rules sync across windows. (#447, #505, #512)
- **File Info** — The panel was rebuilt around lazy-loaded sections and a field picker (default / all / custom, with optional hiding of empty fields), plus a source metadata section and video thumbnail cycling. The viewer can show the camera's autofocus area. (#489)
- **Performance** — Large libraries browse and scan faster: viewport-first thumbnail loading, indexed search exclusions, debounced folder search, quicker grid layout and scrollbar, exiftool-rs reuse per worker, and thumbnail caching for small images. (#435, #507, #548)
- **Languages** — Vietnamese and Czech, 17 in total. On first run the language is picked from the system locale. (#510, #526)

## New Features and Improvements

- Batch rename for selected files. (#418)
- Cloud-only files (OneDrive Files On-Demand, macOS dataless) are indexed and shown without downloading. Lap never downloads them automatically; actions that need the original stay disabled until the file is local. (#394, #431)
- The theme can follow the system light/dark setting. (#518)
- Favorites-only filter for the current view. The file type filter is now single-select and no longer affects sidebar counts or album covers. (#482, #515)
- Smart albums: folder/file name rules and searchable pickers for long value lists (tags, people, cameras, lenses, and so on). (#427, #522)
- Copy file paths with ⌥⌘C / Ctrl+Shift+C. (#520)
- The thumbnail cache can be moved to another drive. (#437)
- Add folders to an album by drag and drop. (#436)
- Space toggles quick preview and pauses videos; Z toggles zoom. Shift+rating/tag shortcuts can auto-advance to the next photo. (#446, #463)
- Sort by added order; the library switcher shows file counts.
- Model downloads resume after a network failure or restart. (#511)
- Previews for Affinity documents (.af, .afphoto, .afdesign, .afpub). (#543)
- Experimental Arch Linux recipe in `contrib/aur`. (#416)
- The permanent-delete choice is remembered. (#509)
- Fullscreen shows metadata badges; tooltips and the shortcut list include viewer shortcuts. (#472, #545, #556)
- Refreshing a folder now also syncs the files directly inside it, catching same-name edits that leave the folder timestamp unchanged.
- VOB videos are now recognized and indexed.
- The database migrates automatically. Existing libraries re-read metadata once to fill the new fields.

## Bug Fixes

- Folder deletion is safer: the target is fixed before confirmation and re-checked before deletion; album roots and paths containing the library database are rejected. (#499)
- Shortcuts match the character printed on the key rather than the QWERTY position, fixing AZERTY, Dvorak, and Colemak. (#487)
- Multi-selection: delete/move no longer breaks on unloaded rows, filmstrip Space toggling works, focus survives scope changes, and drag-move keeps the viewport and selection. (#473, #483, #532)
- Sidebar counts refresh after file and catalog changes. (#459, #533)
- Video: Escape keeps working after using player controls, cleaner overlays while scrubbing, unknown durations display properly, and MP4 plays directly on Linux without remuxing. (#461, #478, #514)
- GPS stored as SRATIONAL (vivo/MediaTek JPEGs) now shows on the map; Nikon lens IDs resolve; map selection and cluster thumbnails line up. (#342, #449, #453)
- Dialogs take focus when opened, so Delete works immediately. (#477)
- Better contrast for disabled text and the purple theme; fixed a WebKit memory loop on Linux with rated files. (#410, #495, #540)
- The tag panel keeps selection and scroll position and no longer redraws the whole window; long tag paths show on hover. (#536, #541, #542)
- File Info no longer flashes empty between files; offline and cloud-only files show their catalog fields right away.
- Windows MSI checks the VC++ runtime version; AppImage and Ubuntu 24.04 build fixes. (#323)
- Dates follow the Windows regional format settings. (#419)
- Albums recover after reconnecting storage. (#351)
- Fixed navigation within RAW pairs and kept the selection stable in the duplicate finder.

## Downloads and Updates

Download the matching macOS, Windows, Linux DEB, or AppImage package from the [v0.4.0 release](https://github.com/julyx10/lap/releases/tag/v0.4.0). See [Getting Started](/guide/getting-started) for installation and update guidance.

For AppImage installations, download the new AppImage instead of using the built-in updater. The embedded update information and `.zsync` files support delta updates through compatible external tools such as AppImageUpdate and AppImageLauncher.
