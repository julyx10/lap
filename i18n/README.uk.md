Lap — це менеджер фотографій із відкритим кодом і локальним підходом для перегляду сімейних альбомів, швидкого пошуку старих світлин та керування великими особистими медіатеками офлайн.
Це орієнтована на конфіденційність альтернатива хмарним фотосервісам: без примусового завантаження, локальний ШІ-пошук, робочий процес із пріоритетом тек і безплатне використання.

## Завантажити Lap

Відкрийте сторінку [останнього випуску](https://github.com/julyx10/lap/releases/latest), потім завантажте файл, що відповідає вашій системі:

| Платформа | Пакунок | Примітка |
| :-- | :-- | :-- |
| **macOS (Apple Silicon / Intel)** | `_aarch64.dmg` / `_x64.dmg` | Нотаризовано Apple |
| **Windows 10/11 (x64 / ARM64)** | `_x64_en-US.msi` / `_arm64_en-US.msi` | Без підпису — якщо SmartScreen блокує завантаження, натисніть **Усе одно зберегти** |
| **Linux (x64 / ARM64)** | `_amd64.deb` / `_arm64.deb` | Для дистрибутивів на основі Debian (Ubuntu, Debian, Linux Mint тощо) |
| **Linux (x64 / ARM64)** | `_amd64.AppImage` / `_aarch64.AppImage` | Зробіть файл виконуваним, потім двічі клацніть для запуску |

### macOS з Homebrew

```bash
brew tap julyx10/lap
brew install --cask lap
```

## Чому Lap

- **Спроєктовано з пріоритетом локальності**: ваші світлини лишаються на вашому власному диску, без обов'язкового хмарного облікового запису чи завантаження.
- **Без прив'язки до бібліотеки**: працюйте безпосередньо з наявними теками, замість імпортувати все в закриту базу даних.
- **Приватні ШІ-інструменти**: пошук, схожість, розумні теги та функції розпізнавання облич працюють локально на вашому пристрої.
- **Створено для великих колекцій**: оптимізовано для плавного перегляду й упорядкування бібліотек із понад 100 000 файлів.
- **Відкритий код і безплатно**: без підписки, без примусової екосистеми та з кодом, який можна перевірити.

## Функції

- **Гнучкий перегляд бібліотеки** за датою, текою, місцем, камерою, об'єктивом, тегами, оцінками та обличчями, з сортуванням і пошуком.
- **Робочий процес із пріоритетом тек** з кількома бібліотеками, імпортом/експортом перетягуванням, імпортом/експортом копіюванням-вставленням, синхронізацією з файловою системою та безпечними операціями переміщення/копіювання/видалення.
- **Локальний ШІ-пошук** для текстових запитів, візуальної схожості, об'єктів, кластеризації облич і необов'язкового багатомовного пошуку понад 50 мовами.
- **Розумні альбоми** зберігають засновані на правилах подання з власним групуванням і сортуванням.
- **Імпорт із упорядкуванням за датою** з макетами за днем, місяцем, роком або однією текою, оригінальними назвами файлів і пропуском дублікатів.
- **Колекції та теги** для групового впорядкування вибраних файлів без переміщення чи дублювання оригіналів.
- **Очищення від дублікатів** зі зведенням місця, яке можна вивільнити, та груповим видаленням у наборах дублікатів.
- **Інструменти відбору й порівняння**, включно з чотирипанельним переглядом порівняння зображень.
- **Вбудоване редагування** для обрізання, вирівнювання під довільним кутом, обертання, віддзеркалення, зміни розміру та базового коригування зображень.
- **Фотоколаж** для створення з вибраних фотографій сітки, мозаїки чи стосу фото.
- **Apple Live Photos і Google Motion Photos** із відтворенням руху та уніфікованим фільтром розумних альбомів.
- **Пари RAW + JPEG/HEIC** показуються як один елемент, а пов'язані файли тримаються разом під час файлових операцій.
- **Налаштовувані мініатюри й попередній перегляд RAW** із використанням рендерингу RAW або вбудованого попереднього перегляду камери, з регульованою яскравістю та показом пар RAW+JPEG.
- **Інтерактивний карта-перегляд** для дослідження фотографій і відео з геоданими в кластерах, що відповідають поточним фільтрам.
- **Перегляд альбомів офлайн**: альбоми на від'єднаних або мережевих сховищах лишаються видимими завдяки кешованим мініатюрам.
- **Широка підтримка форматів** для понад 60 форматів фотографій, RAW і відео.

## Метадані, колекції та переміщення файлів

Lap працює з пріоритетом тек, але не всі дані, показані в Lap, вбудовано в оригінальний файл. Ця відмінність важлива, якщо ви також керуєте тими самими теками у Finder, Провіднику чи іншому фотозастосунку.

### Що лишається з файлом

- Ваші оригінальні фотографії та відео завжди лишаються звичайними файлами в наявних теках.
- Метадані, уже вбудовані у файл, як-от EXIF-дата зйомки, камера, об'єктив, GPS та орієнтація, читаються з цього файлу, коли Lap індексує його.
- Збереження вбудованого редагування зображення записує отримане зображення у вибране місце призначення.
- Коли ви перейменовуєте, переміщуєте, копіюєте чи видаляєте файли **в Lap**, Lap одночасно оновлює свій локальний каталог. Він також тримає разом підтримувані згруповані елементи, як-от компоненти Apple Live Photo, побічні файли AAE та активовані пари RAW + JPEG/HEIC.

### Що Lap зберігає локально

Наведене нижче є даними бібліотеки Lap. Вони зберігаються в локальній базі даних або конфігурації бібліотеки Lap і не записуються в EXIF, IPTC чи побічні файли XMP:

- Колекції, теги, коментарі, обране, оцінки та стани відбору (включно з «Вибраними» та «Відхиленими»)
- Розумні альбоми та їхні правила, групування, сортування й порядок
- Дані ШІ-пошуку, дані облич, мініатюри та інші дані індексу/кешу

Ці дані не переміщуються разом із файлом, коли його копіюють, експортують чи переміщують за межі Lap, і вони не доступні автоматично іншим застосункам.

### Робота з файлами за межами Lap

Lap може повторно сканувати теки та виявляти багато змін у файловій системі. Але зміни, внесені за межами Lap — як-от перейменування, переміщення, заміна чи копіювання файлів — можуть порушити впорядкування, що зберігається лише в Lap.

Для найнадійніших результатів перейменовуйте та переміщуйте файли в Lap, коли ви покладаєтеся на колекції, теги, коментарі, обране, оцінки чи стани відбору. Якщо ви також керуєте файлами за межами Lap, створюйте резервні копії бази даних і конфігурації Lap разом зі своїми світлинами. Ви можете керувати розташуванням бази даних і створювати резервну копію в **Налаштування → Сховище**.

Видалення бази даних або конфігурації Lap вилучає ці локальні дані впорядкування та індексу, але не видаляє ваші оригінальні медіафайли.

## Видалити Lap

Lap працює безпосередньо з наявними теками ваших фотографій. Видалення Lap або його файлів бази даних і кешу **не** видаляє ваші оригінальні фотографії.

Стандартні кроки видалення вилучають застосунок. Щоб видалити Lap повністю, спершу закрийте Lap, видаліть застосунок, потім видаліть його локальну базу даних, кеш мініатюр і файли конфігурації за допомогою команди очищення для вашої платформи.

### macOS

Якщо ви встановили Lap за допомогою Homebrew:

```bash
brew uninstall --cask lap
```

За ручного встановлення закрийте Lap і перемістіть `Lap.app` з теки `Applications` у Кошик.

Щоб видалити всі файли бази даних, кешу та конфігурації Lap:

```bash
rm -rf "$HOME/Library/Application Support/com.julyx10.lap" \
       "$HOME/Library/Caches/com.julyx10.lap" \
       "$HOME/Library/WebKit/com.julyx10.lap"
rm -f "$HOME/Library/Preferences/com.julyx10.lap.plist"
```

### Windows

Відкрийте **Налаштування > Застосунки > Установлені застосунки**, знайдіть **Lap** і виберіть **Видалити**.

Потім відкрийте PowerShell і видаліть усі файли бази даних, кешу та конфігурації Lap:

```powershell
Remove-Item -Recurse -Force -ErrorAction SilentlyContinue "$env:LOCALAPPDATA\com.julyx10.lap"
Remove-Item -Recurse -Force -ErrorAction SilentlyContinue "$env:APPDATA\com.julyx10.lap"
```

### Linux

Для встановлень DEB видаліть пакунок:

```bash
sudo apt remove lap
```

Для встановлень AppImage закрийте Lap і видаліть завантажений файл `.AppImage`.

Потім видаліть усі файли бази даних, кешу та конфігурації Lap:

```bash
rm -rf "$HOME/.local/share/com.julyx10.lap" \
       "$HOME/.cache/com.julyx10.lap" \
       "$HOME/.config/com.julyx10.lap"
```

Якщо ви вибрали власний каталог зберігання бази даних у налаштуваннях Lap, видаліть цей каталог окремо, переконавшись, що він містить лише файли бази даних Lap.

## Зібрати з початкового коду

Вимоги: Node.js 20+, pnpm, стабільна версія Rust.

```bash
# Системні залежності для macOS
xcode-select --install
brew install nasm pkg-config autoconf automake libtool cmake

# Системні залежності для Linux
# sudo apt install libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev \
#   patchelf nasm clang pkg-config autoconf automake libtool cmake

# Клонування та збирання
git clone --recursive https://github.com/julyx10/lap.git
cd lap
git submodule update --init --recursive
cargo install tauri-cli --version "^2.0.0" --locked
./scripts/download_models.sh            # Windows: .\scripts\download_models.ps1
./scripts/download_ffmpeg_sidecar.sh    # Windows: .\scripts\download_ffmpeg_sidecar.ps1
cd src-vite && pnpm install && cd ..
cargo tauri dev
```

Дистрибутивні пакунки можуть компонуватися із системною libheif (1.17 або новішою) замість вбудованих libheif і libde265. Установіть `LAP_SYSTEM_LIBHEIF=1` для збирання. Тоді підмодулі `third_party/libheif` і `third_party/libde265` не потрібні. Декодування HEVC залежить від кодеківних плагінів системної libheif.

## Підтримувані формати

Lap підтримує понад 60 форматів фотографій, RAW і відео.

| Тип | Формати |
| :--- | :--- |
| Зображення | JPG/JPEG/JFIF, PNG, GIF, BMP, TIFF, WebP, HEIC/HEIF/HIF, AVIF, JXL, PSD, EXR, HDR/RGBE, TGA, JPEG 2000 (JP2/J2K/J2C/JPC/JPF/JPX), DDS, DPX, QOI |
| RAW-фотографії | CR2, CR3, CRW, NEF, NRW, ARW, SRF, SR2, RAF, RW2, ORF, PEF, DNG, SRW, RWL, MRW, 3FR, MOS, DCR, KDC, ERF, MEF, RAW, MDC |
| Відео | MP4, MOV, M4V, MKV, AVI, FLV, TS/M2TS, WMV, WebM, 3GP/3G2, F4V, VOB, MPG/MPEG, ASF, DIVX та інші. Відтворення H.264 підтримується на всіх платформах, з автоматичною обробкою сумісності, коли нативне відтворення недоступне. HEVC/H.265 і VP9 нативно підтримуються в macOS. |

### Відтворення відео в Linux

Lap використовує системні плагіни GStreamer для відтворення відео, включно в AppImage. Якщо відео не відтворюється в Ubuntu, Debian або Linux Mint, установіть:

```bash
sudo apt install gstreamer1.0-libav gstreamer1.0-plugins-good
```
